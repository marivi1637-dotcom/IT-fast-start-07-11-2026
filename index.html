Main git commands

  • git status - показує статус файлів у робочій області
  • git branch - показує список гілок та поточну гілку
  • git commit - фіксує зміни у локальному репозиторії
  • git push - завантажує зміни у віддалений репозиторій
  • git checkout - переключається між гілками
  • git pull- команда зміни з віддаленого репозиторію та одразу інтегрує їх у поточну локальну гілку
  • git remote- інструмент для керування підключеннями до віддалених репозиторіїв
